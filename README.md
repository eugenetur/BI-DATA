## Scope and sources

These are portfolio and practice artefacts. Figures displayed in them are exercise/report outputs, not a claim of revenue generated or workplace impact. The Adidas dashboard uses Poland/PLN presentation labels while the workbook also contains US source geography; that distinction should be retained when interpreting it.

The files preserve the original project state. Complete raw-data packages, transformation provenance and refresh instructions are not supplied for every project. The case studies distinguish original screenshots from separate browser simulations using illustrative data.

For additional Excel demonstrations and workbook versions, see [Excel](https://github.com/eugenetur/Excel). The related public SQL exploration is in [MySQL](https://github.com/eugenetur/MySQL).
